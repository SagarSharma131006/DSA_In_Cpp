# Arrays

## Overview

Arrays are one of the most fundamental data structures in DSA.

They store elements of the same type in contiguous memory locations.

## What I Will Learn

- Array Traversal
- Array Manipulation
- Searching
- Two Pointer
- Prefix Sum
- Sliding Window
- Kadane's Algorithm
- Subarrays
- Frequency Counting
- Array Optimization Techniques
